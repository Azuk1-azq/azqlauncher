Robloxを、もっと速く。もっと自分らしく。Roblox, faster and unmistakably yours.

AZQLAUNCHERは、Robloxを起動する前にFPS上限の解放と描画設定を整え、フォント・スカイボックス・カーソル・死亡音まで好みに差し替えるWindows用ランチャーです。難しい設定ファイルは触りません。ファイルを選んでボタンを押すだけで、次の起動から反映されます。AZQLAUNCHER is a Windows launcher that unlocks your frame rate and tunes rendering before Roblox starts, then swaps in your own font, skybox, cursor and death sound. No config files to edit. Pick a file, press a button, and it takes effect on the next launch.

起動前にすべて整え、あとは邪魔をしないEverything is set before launch, then it steps aside

ランチャーは、Robloxを起動する直前に設定とModのファイルを書き込みます。起動を見届けると自動で閉じる設定が初期状態なので、遊んでいる間は何も動いていません。Right before Roblox starts, the launcher writes your settings and mod files. By default it closes itself once Roblox is running, so nothing of it stays open while you play.

FastFlags

FPS上限の解放と描画設定FPS unlock and rendering

目標FPS、PostFXの無効化、レンダリング品質の軽量化、描画API(D3D11 / D3D10 / Vulkan / OpenGL)を画面から選べます。Set a target FPS, disable PostFX, lower render quality and pick a graphics API (D3D11, D3D10, Vulkan, OpenGL) from the UI.

Mods

見た目と音のカスタマイズLook and sound

カーソル、死亡時の効果音、スカイボックス、UIフォントを差し替えます。汎用Modsフォルダのファイルもそのままコピーされます。Replace the cursor, death sound, skybox and UI font. Anything in the general Mods folder is copied in as well.

Browser

ブラウザからそのまま起動Launch from the browser

roblox-player と roblox のURIを登録するので、サイトの「プレイ」ボタンからでもランチャー経由で起動できます。Registers the roblox-player and roblox URI schemes, so the Play button on the website goes through the launcher.

Update

Robloxの更新に追従Survives Roblox updates

更新で新しいバージョンフォルダが作られたことを検知し、新しい方へFastFlagsとModsを再適用します。更新中はその旨を表示します。上書き前の元ファイルはバックアップされ、「解除」で確実に元へ戻せます。Detects the new version folder created by an update and re-applies flags and mods there. It shows an "Updating Roblox" state while it waits. Original files are backed up first, so Clear really restores them.

Vanilla

ワンクリックで標準起動One-click vanilla

「標準起動 (Modsなし)」を押すと、FastFlagsとModsを元に戻して標準のクライアントを起動します。ブラウザ起動時の既定にもできます。"Vanilla Launch" restores the original files and starts the stock client. You can make it the default for browser launches too.

UI

日本語と英語に対応Japanese and English

表示言語はシステムに合わせて自動で切り替わり、設定から固定もできます。実行ログもアプリ内で確認できます。The language follows your system and can be pinned in Settings. A built-in log view shows what happened on each launch.

Quick Join

ゲームURLを貼ってすぐ参加Paste a link and join

ゲームURL・プレイスID・プライベートサーバーのリンクを貼ってEnterで参加できます。最近遊んだ8件は履歴に残ります。Paste a game URL, place ID or private server link and press Enter. Your last 8 games are kept as history.

Theme

ライト / ダーク / システム連動Light, dark or follow system

既定はWindowsの設定に追従し、起動中に切り替えても自動で変わります。設定から手動でも選べます。Follows Windows by default and switches live while running. You can also pick one manually in Settings.

Workflow

ショートカットと自動保存Shortcuts and autosave

Ctrl+1〜5でページ移動、Ctrl+Enterで起動、Ctrl+Sで保存して反映。FastFlagsの変更は自動保存され、ウィンドウはリサイズでき、サイズも記憶されます。Ctrl+1-5 switch pages, Ctrl+Enter launches, Ctrl+S saves and applies. FastFlags autosave, and the window is resizable and remembers its size.

Logs

ログ保存と設定の持ち運びSaved logs and portable settings

ログは日ごとにファイル保存(14日分)。設定のエクスポート/インポートやFPSプリセット(60 / 144 / 240 / 無制限)にも対応しています。Logs are saved per day for 14 days. Settings can be exported and imported, and FPS presets (60 / 144 / 240 / unlimited) are built in.

許可リストにあるFastFlagsだけを書き込むOnly allowlisted FastFlags are written

JSONエディタに好きなキーを書けますが、適用されるのは内蔵の許可リストにあるものだけです。それ以外は起動時に除外され、ログに残ります。The JSON editor accepts any key, but only entries on the built-in allowlist are applied. The rest are dropped at launch and noted in the log.

DFIntTaskSchedulerTargetFpsFFlagDisablePostFxFFlagDebugGraphicsPreferVulkanDFIntDebugFRMQualityLevelOverrideFIntDebugForceMSAASamplesDFIntTextureQualityOverride
{
  "DFIntTaskSchedulerTargetFps": 240,
  "FFlagDisablePostFx": true,
  "FFlagSomethingNotOnTheList": true
}
// JSON Valid (1 non-allowlisted key will be ignored)

フォントもスカイボックスも、ボタンひとつOne button for fonts, skyboxes and more

ファイルかフォルダを選ぶだけです。ファイルの置き場所やRobloxの内部フォルダを自分で探す必要はありません。選んだものは設定に保存され、起動のたびに自動で適用されます(変更は次回の起動時に反映されます)。Pick a file or a folder and you are done. No digging through Roblox's internal folders. Your choice is saved and applied on every launch (changes take effect on the next launch).

フォントFontフォントファイルを選択Select Font File

.ttf か .otf を1つ選ぶと、Robloxが使う主要なUIフォント(Source Sans Pro、Gotham、Builder Sans)がすべてそのフォントに置き換わります。Choose one .ttf or .otf and it replaces every main UI font Roblox uses (Source Sans Pro, Gotham and Builder Sans).

スカイボックスSkyboxスカイボックスフォルダを選択Select Skybox Folder

bk, dn, ft, lf, rt, up で終わる名前の6枚を入れたフォルダを選びます。面ごとに正しい場所へ自動でコピーされます。Choose a folder with six images whose names end in bk, dn, ft, lf, rt and up. Each face is copied to the right place for you.

死亡音Death sound音声ファイルを選択Select Audio

mp3、wav、m4a、aac、flac、wma も選べます。ogg 以外はFFmpegで自動変換されます。FFmpegは初回だけ自動でダウンロードされるため、そのときはネット接続が必要です。Pick mp3, wav, m4a, aac, flac or wma too. Anything that is not ogg is converted with FFmpeg, which is downloaded automatically the first time, so you need a connection then.

カーソルCursorカーソル画像 (.png) を選択Select Cursor (.png)

自分のPNGのほか、Windowsで使用中のカーソルや昔のクラシックカーソルをラジオボタンで選べます。Use your own PNG, or choose your current Windows cursor or the classic one with a radio button.

フォント / スカイボックス / 死亡音 / カーソルFont / Skybox / Death sound / Cursorそれぞれの横にある「解除」を押します。Mods全体は、ワンクリックでオフにもできます。Press Clear next to each one. You can also switch all mods off with a single checkbox.

Open Source

ソースコードは、すべて公開していますEvery line of source is public

ランチャーはRobloxのフォルダと設定に手を入れるツールです。だから何をしているのかを、誰でも自分の目で確かめられるようにしました。気になる処理はコードで読めて、自分でビルドして動かせて、改善案はそのまま提案できます。A launcher touches Roblox's folders and settings, so you should be able to see exactly what it does. Read any behavior in the code, build it yourself, and send improvements straight back.

ダウンロードして使うDownload and run

Windows 10/11 と .NET 8 ランタイムが必要です。Robloxは先にインストールしておいてください。zipを展開して AZQLAUNCHER.exe を起動すれば使えます。Needs Windows 10 or 11 and the .NET 8 runtime. Install Roblox first. Unzip the archive and run AZQLAUNCHER.exe.

AZQLAUNCHER.zip をダウンロードDownload AZQLAUNCHER.zip

ソースからビルドする場合Or build from source

  1. リポジトリのフォルダでビルドします。Build from the project folder.
  2. 出力フォルダの AZQLAUNCHER.exe を起動します。Run AZQLAUNCHER.exe from the output folder.
  3. 初回の紹介ガイドを読んで「はじめる」を押します。Read the welcome guide and press Get Started.
  4. FastFlagsやModsを選び、「Robloxを直接起動」を押します。Pick your flags and mods, then press Launch Roblox.
# build
dotnet build -c Release

# or a single-folder release
dotnet publish -c Release -r win-x64 \
  --self-contained false
